제안서에 적은 기능이 이미 화면에서 동작합니다

한글 파일에 흩어져 있던 수학 문항을 한곳에서 작성하고, 분류하고, 다시 찾아 쓰는 화면입니다. 소리 없이 자막으로 진행되며 1분 44초입니다.

영상에서 보시는 순서

제목을 누르면 영상의 해당 장면에서 바로 재생됩니다.

이 데모에서 확인하실 수 있는 것

공고에 적으신 요구사항 중 판단이 가장 어려운 부분부터 먼저 만들어 확인했습니다.

버튼으로 넣는 수식
분수, 루트, 지수, 첨자, 적분처럼 자주 쓰는 표기를 버튼으로 고르고 빈칸을 채웁니다. 복잡한 표기법을 외우지 않아도 됩니다.
나중에 다시 고칠 수 있는 수식
수식을 그림으로 굳혀 저장하지 않고 입력한 내용을 함께 보관합니다. 문항을 다시 열어 숫자만 바꿔 변형 문제를 만들 수 있습니다.
직접 그리는 그래프와 도형
좌표평면, 일차·이차함수, 점, 선분, 삼각형, 원을 시스템 안에서 만듭니다. 계수를 바꾸면 곡선이 바로 움직입니다.
4단계 분류와 본문 검색
과목·대분류·중분류·소분류에 태그와 난이도를 더해 정리하고, 문제 내용으로 찾아 기존 문항을 복사해 씁니다.
전체 문항에 한 번에 적용되는 표시 설정
글꼴, 글자 크기, 줄 간격, 선택지 배치를 설정 화면에서 바꾸면 이미 저장된 문항 전체에 적용됩니다. 문항마다 고칠 필요가 없습니다.
데이터 내보내기와 백업
문항 데이터와 원본 이미지를 통째로 내려받습니다. 특정 개발사만 열 수 있는 형식이 아닙니다.

개발이 끝난 뒤에도 대표님 것입니다

이 프로젝트에서 지키겠다고 말씀드린 조건입니다.

  • 60일 안에 완료 공고의 90일 일정을 60일로 제안드립니다. 실제 문항 샘플로 수식과 작도 방식을 확인하는 과정, 백업 복원 시험, 대표님의 최종 사용 검수는 줄이지 않습니다.
  • 2~3주차부터 직접 사용 완성될 때까지 기다리지 않으셔도 됩니다. 문항 작성과 수식 입력부터 동작하는 상태로 열어 드리고, 매주 의견을 반영합니다.
  • 서버와 데이터는 고객 명의 서버, 데이터베이스, 파일 저장 공간, 도메인을 대표님 명의로 개설합니다. 전체 소스코드와 문항 데이터, 원본 이미지, 운영 문서를 인도합니다.
  • 오픈 후 2개월 무상 유지보수 실제로 쓰시면서 나오는 저장 오류, 검색 오류, 화면 깨짐, 브라우저 호환 문제를 무상으로 고칩니다.

다음은 이렇게 진행하고 싶습니다

  1. 지금 작성 중이신 대표 문항 10~20개를 함께 보고 싶습니다. 가장 복잡한 수식과 그림이 무엇인지 확인하면, 시스템에서 직접 작도할 범위와 이미지로 올릴 범위를 첫 주에 정할 수 있습니다.
  2. 미팅에서는 이 화면에 대표님 문항을 직접 입력해 보시고, 저장한 뒤 다시 검색해서 고치는 과정까지 보여드리겠습니다.
  3. 확정된 분류 기준과 표시 형식을 정리해 60일 일정의 주차별 검수 시점을 함께 맞추겠습니다.
