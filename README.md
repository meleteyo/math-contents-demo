# 문항서재 · 수학 문항 관리 사전 데모

위시켓 프로젝트(수학 콘텐츠 관리 시스템) 지원 단계에서 제작한 사전 데모 소개 페이지입니다.
고객이 링크 하나로 동작 화면을 바로 확인할 수 있도록 만들었습니다.

**공개 주소: https://meleteyo.github.io/math-contents-demo/**

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 소개 페이지. 데모 영상과 19개 장면 목차(누르면 해당 시점으로 이동) |
| `design.html` | 기술·데이터 설계 설명서 |
| `assets/math-contents-demo.mp4` | 데모 영상 (1분 44초, 1600×1080, 무음·자막) |
| `assets/poster.jpg` | 영상 재생 전 표시되는 대표 화면 |

## 공개 범위

이 저장소에는 소개 페이지와 데모 영상만 있습니다. 실제 애플리케이션 소스코드는 비공개로 유지합니다.

영상은 개발용 예제 문항과 임시 데모 계정만 사용해 촬영했으며, 실제 고객 데이터나 서버 주소는
포함되어 있지 않습니다.

## 수정 방법

`index.html`의 장면 목차는 영상 편집 타임라인(`motion-timeline.json`)에서 생성했습니다.
각 항목의 `data-time` 값이 영상 시작 시각(초)이며, 영상 앞머리의 제목 화면 4초가 더해져 있습니다.
영상을 다시 만들면 목차의 시각도 함께 갱신해야 합니다.
