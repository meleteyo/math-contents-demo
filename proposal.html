먼저 말씀드리고 싶은 차별점

저는 이번 프로젝트에 단순히 “개발할 수 있다”는 내용만으로 지원하지 않습니다.

공고를 확인한 뒤 요구사항을 직접 분석하여 문항 작성, 버튼식 수식 입력, 함수 그래프와 기본 도형 작성, 이미지 관리, 자동저장, 검색·복사, 전체 표시 설정, 데이터 내보내기까지 실제로 동작하는 사전 데모를 이미 제작했습니다. 미팅에서 설명 자료나 화면 그림만 보여드리는 것이 아니라, 대표 문항을 직접 입력하고 저장한 뒤 다시 검색·수정하는 전 과정을 바로 시연할 수 있습니다.

제가 이 프로젝트에 적합한 핵심 이유는 다음과 같습니다.

고객의 요구를 듣고 분석하여 실제 서비스로 만드는 일을 경력의 많은 부분에서 수행했습니다

기획서가 완성되지 않은 상태에서도 고객의 업무를 듣고 필요한 기능, 제외할 기능, 완료 기준을 정리해 개발해 왔습니다. 개발자가 없는 고객사와도 어려운 기술 용어보다 실제 사용 과정과 결과를 기준으로 소통하는 데 익숙합니다.

수학 관련 애플리케이션 개발 경험과 수학 콘텐츠 실무 역량을 함께 보유하고 있습니다

저는 수학 관련 애플리케이션을 개발한 경험이 있습니다. 함께 참여하는 협업 파트너는 수학 온라인 문제 기획·편집 분야에서 15년 이상의 실무 경험을 보유하고 있습니다. 개발자 관점만으로 판단하지 않고 실제 문항 제작자의 관점에서 수식, 도형, 단원 분류와 편집 흐름을 검토할 수 있습니다.

지난 1년간 실제 대기업 웹 서비스에서 AI 기반 개발을 적용해 왔습니다

AI를 단순 시연이나 개인 프로젝트가 아니라 실제 사용자가 이용하는 대기업 웹 서비스의 개발과 유지보수에 활용해 왔습니다. 요구사항 분석, 기능 구현, 테스트, 오류 수정과 문서화 속도를 높이면서 최종 결과는 개발자가 직접 검토하는 방식입니다. 이 경험을 바탕으로 공고의 90일 일정을 60일로 단축하여 제안드립니다.

개발에서 끝나지 않고 서비스 오픈과 장기 운영을 경험했습니다

최근 여러 서비스를 개발 단계부터 실제 오픈, 이후 장기간 유지보수까지 담당했습니다. 운영 중 발생하는 데이터 문제, 사용자 문의, 장애 대응, 백업과 복구, 계속되는 기능 변경을 경험했기 때문에 “완성된 프로그램”보다 “오래 안정적으로 사용할 수 있는 서비스”를 기준으로 설계합니다.

고객이 개발사에 의존하지 않는 구조를 만들겠습니다

문항 추가·수정, 단원·태그 관리, 글꼴·크기·배치 변경, 이미지 재사용과 데이터 내보내기를 대표님이 직접 할 수 있게 구성합니다. 서버와 도메인은 고객 명의로 만들고 전체 소스코드, 데이터 구조, 운영·복원 설명서를 인도합니다. 오픈 후에는 2개월간 계약 범위의 오류를 무상으로 유지보수하겠습니다.

빠르게 확인하고 매주 개선하는 방식으로 소통하겠습니다

완성 시점까지 기다렸다가 한꺼번에 검수하지 않겠습니다. 2~3주차부터 문항 작성과 수식 입력 등 작동하는 핵심 기능을 대표님이 직접 사용해 볼 수 있도록 제공하고, 이후 매주 의견을 확인하여 수정·보완하겠습니다. 카카오톡, 전화, 이메일과 화상 미팅 중 대표님이 편한 방법으로 소통하며 문의에 빠르게 응답하겠습니다.

이번 프로젝트는 지원서를 제출하기 전부터 핵심 기능을 구현해 볼 만큼 관심과 준비를 가지고 접근했습니다. 아래에는 제가 이해한 요구사항과 60일 수행 방안을 간략히 정리했습니다.

프로젝트에 대한 이해

공고를 읽고 이 프로젝트의 핵심을 다음과 같이 이해했습니다.

지금까지 한글 파일에 흩어져 있던 수학 문항을 한곳에서 작성하고 보관하면서, 대표님이 개발자의 도움 없이 단원별로 분류하고 검색하여 다시 사용할 수 있는 시스템이 필요합니다. 앞으로 수천 건의 문항이 쌓일 예정이므로 당장 화면만 만드는 것이 아니라, 나중에 학생용 서비스와 결제 기능이 추가되더라도 처음부터 다시 만들지 않을 구조가 중요합니다.

지원 단계에서 준비한 내용

공고의 요구사항을 구체적으로 이해하기 위해 핵심 기능이 실제로 동작하는 사전 데모 프로그램을 제작했습니다. 데모에서는 다음 기능을 직접 확인하실 수 있습니다.

  • 관리자 로그인
  • 객관식 문항 본문, 선택지, 정답 입력
  • 버튼을 이용한 분수, 루트, 지수, 적분 등의 수식 입력
  • 좌표평면, 일차·이차함수, 점, 선분, 삼각형, 원 작성
  • 이미지 등록과 기존 이미지 재사용
  • 입력 화면과 실제 문항 모양을 함께 확인하는 미리보기
  • 작성 중 자동저장과 저장 실패 복구
  • 저장된 문항 복사와 수정
  • 4단계 단원 분류, 태그, 난이도, 본문 검색
  • 전체 문항의 글꼴, 글자 크기, 줄 간격, 선택지 배치 변경
  • 문항 데이터와 원본 이미지 전체 내보내기

미팅에서는 화면 시안만 보여드리는 것이 아니라, 실제로 문항을 하나 입력하고 저장한 뒤 다시 검색하고 수정하는 과정까지 시연할 수 있습니다.

데모 영상에서 위 과정을 바로 확인하실 수 있습니다

핵심 구현 방안

문항을 만드는 곳과 보관하는 곳을 하나로 만듭니다

문항 본문, 선택지, 정답, 수식, 이미지와 도형을 하나의 편집 화면에서 작성합니다. 별도 파일에 먼저 만들고 다시 옮겨 적을 필요가 없습니다. 작성한 내용은 자동으로 임시저장되며, 정식 저장 전에는 빠진 항목을 알기 쉽게 안내합니다.

수식은 버튼으로 쉽게 입력하고 나중에도 수정할 수 있게 합니다

분수, 루트, 지수, 첨자, 함수, 합, 적분, 부등호 등 자주 사용하는 수식 틀을 버튼으로 넣습니다. 사용자는 복잡한 표기법을 외울 필요 없이 빈칸을 채우는 방식으로 작성할 수 있습니다.

수식을 단순 이미지로 저장하지 않고 원래 입력 내용을 함께 보관합니다. 따라서 문항을 다시 열어 수식을 수정할 수 있고, 향후 학생용 화면에서도 같은 수식을 재사용할 수 있습니다.

도형은 직접 작도와 이미지 업로드를 함께 사용합니다

사전 데모를 직접 제작하면서 작도 범위를 검토해 본 결과, 모든 고등수학 그래프와 기하 표현을 시스템 안에서 자유롭게 작성하도록 만드는 것은 이번 예산과 일정에서 현실적이지 않습니다.

일차·이차함수, 좌표평면, 점, 선분, 삼각형, 원처럼 자주 쓰이는 기본 도형은 시스템에서 직접 만들고 다시 수정할 수 있게 구현하겠습니다. 그러나 복잡한 고등수학 그래프, 특수한 기하 도형, 교재에서 별도로 제작한 삽화는 이미지로 업로드하여 사용하는 방식이 더 빠르고 정확할 수 있습니다.

따라서 계약 초기에 실제 문항 샘플을 확인한 뒤 다음과 같이 구분하겠습니다.

  • 자주 반복되고 값만 바뀌는 그래프와 기본 도형: 시스템 안에서 직접 작성
  • 복잡하거나 사용 빈도가 낮은 그래프와 특수 도형: 이미지 업로드
  • 향후 반복 사용량이 많아진 특수 도형: 별도 기능으로 추가

이 방식은 제한된 기간 안에 불완전한 만능 작도 도구를 만드는 위험을 줄이고, 실제 문항 제작 속도와 결과물 품질을 높일 수 있습니다.

문항 내용과 화면 모양을 분리합니다

문항 내용과 글꼴·글자 크기·줄 간격·선택지 배치를 따로 관리합니다. 대표님이 설정 화면에서 표시 방법을 바꾸면 기존 문항 전체에 적용됩니다. 문항마다 다시 수정하거나 개발사에 요청할 필요가 없습니다.

선택지 순서를 바꿔도 정답이 바뀌지 않게 합니다

정답을 단순히 “2번”으로 저장하지 않고 해당 선택지 자체와 연결합니다. 따라서 선택지 순서를 위아래로 이동해도 올바른 내용이 계속 정답으로 유지됩니다.

저장한 문항의 과거 내용을 보호합니다

문항을 정식 저장할 때마다 새로운 저장본을 만듭니다. 기존 내용을 덮어쓰지 않기 때문에 언제 어떤 내용으로 저장했는지 확인할 수 있습니다. 같은 문항을 여러 창에서 수정할 때도 오래된 화면이 최신 내용을 덮어쓰지 않도록 충돌을 알려줍니다.

수천 건을 찾고 다시 쓰기 쉽게 만듭니다

과목-대분류-중분류-소분류의 4단계로 문항을 정리하고, 하나의 문항에 여러 태그를 붙일 수 있게 합니다. 단원, 태그, 난이도, 상태, 문제 내용으로 검색하고 기존 문항을 복사해 변형 문제를 만들 수 있습니다.

고객이 데이터와 운영 권한을 소유합니다

서버, 데이터베이스, 파일 저장 공간과 도메인은 고객 명의로 개설합니다. 전체 소스코드와 문항 데이터, 원본 이미지, 설명 문서를 인도합니다. 특정 개발사만 열 수 있는 형식이 아니라 일반적으로 활용 가능한 형태로 전체 데이터를 내려받을 수 있게 합니다.

데이터를 안전하게 관리하는 방법

문항, 선택지, 정답, 분류, 태그와 이미지는 서로 연결된 형태로 저장합니다. 단순히 긴 문장 하나로 저장하지 않기 때문에 선택지만 바꾸거나, 특정 단원의 문항만 찾거나, 나중에 학생용 서비스에서 문항과 정답을 분리해 제공할 수 있습니다.

작성 중인 내용과 정식 저장된 내용을 구분합니다. 정식 저장본은 수정할 때마다 새 기록을 남기고, 이미지와 도형도 이미 사용 중인 원본을 덮어쓰지 않습니다.

매일 데이터베이스와 이미지 파일을 함께 백업하고, 백업 파일이 실제로 복원되는지 별도 환경에서 확인하는 절차를 마련합니다. 관리자 화면에서는 최근 백업 성공 여부를 확인할 수 있도록 합니다.

60일 진행 제안

  1. 1주차대표님 인터뷰, 실제 문항 샘플 분석, 단원·태그·표시 기준 확정
  2. 2~3주차문항 입력, 선택지·정답, 수식 입력, 자동저장, 미리보기 구현 및 1차 검수
  3. 4~5주차기본 작도, 이미지 보관함, 분류·태그·검색, 문항 복사와 변경 이력 구현
  4. 6주차전체 문항의 글꼴·크기·배치 설정, 데이터 내보내기, 백업과 복원 기능 구현
  5. 7주차실제 샘플 문항 입력 검수, 사용 편의성 보완, 성능·오류·보안 점검
  6. 8주차고객 명의 서버 배포, 운영 환경 점검, 대표님 사용 교육
  7. 9주차 초반최종 검수, 운영 문서·전체 소스코드·데이터 구조 자료 인도 및 오픈

기간을 줄이더라도 초기에 실제 문항 샘플로 수식과 작도 방식을 확인하는 과정, 백업 복원 시험, 대표님의 최종 사용 검수는 생략하지 않겠습니다. 고객 확인이 필요한 사항을 초기에 집중해서 결정하고, AI 기반 개발로 반복 구현·테스트·문서화 시간을 줄이는 방식으로 60일 안에 완료하겠습니다.

커뮤니케이션과 피드백 반영 방법

프로젝트가 끝날 때까지 기다리지 않고 개발 중인 결과를 빠르게 확인하실 수 있도록 하겠습니다.

1주차에는 대표 문항과 현재 작업 방식을 함께 확인합니다. 2~3주차부터는 문항 작성, 선택지·정답, 수식 입력, 자동저장과 미리보기 등 작동하는 핵심 기능을 직접 사용해 볼 수 있는 테스트 환경을 제공합니다.

이후 매주 한 번 진행 상황과 새로 완성된 기능을 공유합니다. 대표님이 실제로 문항을 입력하면서 전달한 의견은 중요도와 작업 영향을 함께 정리하고, 합의한 우선순위에 따라 다음 주 개발에 반영합니다. 수정된 내용은 다음 검수에서 다시 확인할 수 있도록 하겠습니다.

문의가 들어오면 가능한 빠르게 접수 여부와 확인 예정 시간을 먼저 답변하겠습니다. 서비스 이용에 영향을 주는 오류는 일반적인 개선 의견보다 먼저 확인하며, 바로 해결하기 어려운 경우에도 확인 상황과 다음 안내 시점을 공유하겠습니다.

완료 기준

이 프로젝트는 프로그램이 실행되는 것만으로 완료되었다고 보지 않습니다. 실제 사용자인 대표님이 개발자의 도움 없이 다음 작업을 할 수 있어야 완료입니다.

  1. 실제 샘플 문항을 수식·이미지·기본 도형·선택지·정답까지 직접 입력하고 다시 수정할 수 있어야 합니다.
  2. 단원·태그·문제 내용으로 원하는 문항을 찾고 복사하여 새 문제를 만들 수 있어야 합니다.
  3. 글꼴·크기·간격·선택지 배치를 직접 변경하고 기존 문항 전체에 적용할 수 있어야 합니다.
  4. 선택지 순서를 변경해도 정답이 유지되고, 과거 저장 내용과 변경 기록을 확인할 수 있어야 합니다.
  5. 전체 데이터를 내려받을 수 있고, 백업을 별도 환경에 복원해 문항과 이미지를 확인할 수 있어야 합니다.
  6. 고객 명의 서버에서 정상 운영되며, 운영 방법과 장애 시 확인 방법이 문서로 제공되어야 합니다.

무상 유지보수

서비스 오픈 후 2개월 동안 계약 범위 내 오류를 무상으로 수정하겠습니다.

오픈 후 실제 사용 과정에서 발견되는 저장 오류, 검색 오류, 화면 깨짐, 브라우저 호환 문제 등 계약된 기능이 정상 동작하지 않는 경우를 대상으로 합니다. 새로운 기능 추가, 확정 범위를 넘어서는 작도 도구 추가, 외부 서비스 정책 변경에 따른 작업은 별도 협의하겠습니다.

무상 유지보수 기간이 끝난 뒤에도 운영을 이어갈 수 있도록 선택형 유지보수 방식과 인수인계 방안을 함께 제안드리겠습니다. 특정 개발자에게 계속 의존하지 않도록 소스코드, 데이터, 운영 계정과 문서를 고객이 소유하게 합니다.
